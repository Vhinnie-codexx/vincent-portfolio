# Vincent Nzubechukwu — Portfolio

Personal software engineering portfolio built with React, TypeScript, Vite and Tailwind CSS.

Live site: https://vincent-nzubechukwu.netlify.app/

## Development

```sh
npm ci
npm run dev
```

## Validation

```sh
npm run lint
npm run build
```

Production output is generated in `dist/`. HAVEN and ZUBELTECH are works in progress. Project visuals are illustrative concepts. The contact form opens an email draft and does not send or store submissions.
